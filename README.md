# pet timer

かわいいペットと一緒に勉強・タスク管理をする日本語Webアプリです。

## できること（初期版）
- 猫・犬・うさぎ・ハムスターの選択、名前変更、写真アップロード
- ペットのお世話、ごはん、遊び、お昼寝、ステータス表示
- 集中・休憩・カスタムタイマー、時分秒の指定、終了後カウントアップ
- 終了音の音量・繰り返し設定と試聴
- タスクの追加・編集・完了、複数タグ、優先順位、期限、予定時間
- タスクのリスト／カレンダー切替
- アラーム登録（ページを閉じた状態での鳴動は保証されません）
- 集中・休憩・タスク完了の記録
- JSONバックアップ
- メールアドレス・パスワードによるアカウント登録／ログイン
- PostgreSQLを使ったクラウド保存（DATABASE_URL設定時）

## ローカル起動
1. Node.js 20以上をインストール
2. このフォルダで `npm install`
3. `.env.example` を `.env` にコピー
4. `npm run dev`
5. ブラウザで http://localhost:5173 を開く

DATABASE_URLが空欄の場合、ローカル開発用のJSONファイルにアカウント情報を保存します。
このローカルJSON保存は開発・試用向けです。Render公開時は必ずPostgreSQLを接続してください。

## Renderへの公開
1. GitHubにこのプロジェクトを新しいリポジトリとしてアップロード
2. RenderでBlueprintから `render.yaml` を使ってデプロイ
3. Render PostgreSQLとWeb Serviceを作成
4. `DATABASE_URL` と `JWT_SECRET` が設定されていることを確認
5. 公開後、アカウント登録を行う

## 大切な注意
- この初期版は新規アプリです。以前のpet timerのデータは自動移行されません。
- アラームはブラウザの制約があります。ページを閉じた状態や端末がスリープ中の鳴動は保証できません。
- ブラウザ内でのデータ保存とクラウド同期を使います。大切なデータは定期的にバックアップしてください。
- 公開前にHTTPS、DBバックアップ、パスワードポリシー、メール認証、セキュリティ設定を確認してください。
